## Tesis en una frase

> En 10 minutos podés armar una web que parece profesional y vendérsela a negocios, usando Claude Code + Framer Motion + la skill UI UX Pro Max + componentes de 21st.dev.

## Qué enseña

- [00:00] En 2 minutos se arma una web profesional que se le puede vender a negocios.
- [00:05] Instalar Claude Code.
- [00:08] Para animaciones, ir a la web de Framer Motion, copiar el comando y pegarlo en Claude Code.
- [00:12] Bajarse la skill **UI UX Pro Max** y pedirle a Claude Code que la use.
- [00:16] Ir a la web de **21st.dev**, copiar el comando y pegarlo en Claude Code.
- [00:20] Con buenas instrucciones, en ~10 minutos queda una web vendible.
- [00:30] El canal ofrece una guía de diseño con más skills (captación de leads).

## Procedimiento que propone

1. Instalar Claude Code.
2. Instalar Framer Motion (copiar comando de su web).
3. Instalar la skill UI UX Pro Max.
4. Instalar componentes de 21st.dev (copiar comando).
5. Dar buenas instrucciones a Claude Code.
6. Resultado: web profesional en ~10 minutos.
