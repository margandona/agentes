## Tesis en una frase

> Antes de automatizar cualquier cosa, alguien debe mapear la organización, marcar los procesos donde tiene sentido meter agentes de IA y producir una hoja de ruta de agentes, conservando el valor de por qué se hace cada tarea.

## Qué enseña

- [00:00] Antes de automatizar, alguien debe sentarse con los referentes de cada área para mapear toda la organización.
- [00:05] Marcar los procesos donde tiene sentido meter agentes de IA.
- [00:10] De ahí sale la **hoja de ruta de agentes** (agent roadmap).
- [00:15] Para cada caso de uso, sentarse con los empleados que hacen la tarea para entender todos los pasos actuales.
- [00:22] Lo más importante: **por qué se hace en primer lugar**. Conservar el valor para el cliente, el negocio y el empleado.
- [00:32] Marcar todo el software que se usa en cada paso y confirmar que se puede automatizar con las herramientas que ya se tienen.
- [00:40] El autor ofrece un mapa para 6 rubros con más de 140 casos de uso, con resultados y retorno estimado.
- [01:05] Llamado a la acción: comentar "mapa" para recibirlo.

## Procedimiento que propone

1. Sentarse con los referentes de cada área.
2. Mapear toda la organización.
3. Marcar procesos automatizables con agentes de IA.
4. Producir la hoja de ruta de agentes.
5. Para cada caso de uso: sentarse con los empleados, entender pasos y el "por qué".
6. Marcar el software usado en cada paso.
7. Confirmar que se puede automatizar con las herramientas existentes.
