# Skills

Un skill es un procedimiento ejecutable, no un resumen.

## Reglas

- Carpeta: `skills/<nombre>/SKILL.md`
- `name` del frontmatter == nombre de la carpeta
- `description` en inglés, con triggers
- Sin jerga propia sin definir
- Si necesita archivos extra, van en la misma carpeta (`scripts/`, `references/`)

## Para instalar un skill globalmente

Copiar la carpeta a `~/.config/opencode/skills/<nombre>/` (OpenCode) o `~/.claude/skills/` (Claude Code).
