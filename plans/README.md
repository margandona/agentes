# Planes

Un plan es la implementación concreta de una idea: archivos, orden, verificación.

## Reglas

- Un archivo por plan: `plans/<nombre>.md`
- Usar `templates/plan.md`
- Todo plan tiene criterios de aceptación y un "cómo saber si falló"
- Estado: `borrador` → `aprobado` → `en curso` → `hecho` / `descartado`
